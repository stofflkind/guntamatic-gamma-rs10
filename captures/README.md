# Captures

Raw RS485 captures are intentionally not stored in this repository by default.

They can be large and may contain installation-specific operating data.

For reproducible experiments, document:

- capture date
- controller and room-station model
- bus address
- RS10 setting/value before the change
- RS10 setting/value after the change
- filename used locally
- relevant CRC-valid frames

Small, deliberately selected example captures may be added later after review.
